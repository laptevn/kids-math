1. We are developing web app to learn multiplication from 1 to 10.
2. The kid should learn how to solve multiplication quickly without deep thinking. So it should be like reflexes.
3. When the app is opened a kid can choose 2 modes - learn and test. Learn requires selecting which number she will learn. Let's imagine she chooses 7. Then the app tests how 7 multiplies to 1 to 10.
4. Another mode is to test knowledge. If it's chosen the app gives 20 random cases and scores result. In the end it recommends to learn specific numbers if there are problems with it.
