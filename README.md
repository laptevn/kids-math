# Кристина считает

Мобильная игра для тренировки таблицы умножения от 1 до 10. Работает полностью в браузере, хранит прогресс только на устройстве и устанавливается на домашний экран iPhone или iPad.

## Разработка

```bash
npm install
npm run dev
```

Проверки:

```bash
npm test
npm run build
```

## GitHub Pages

Workflow `.github/workflows/deploy.yml` публикует приложение при каждом push в ветку `master`. После создания репозитория включите **Settings → Pages → Source → GitHub Actions**.

Vite использует относительные пути, поэтому имя будущего репозитория указывать заранее не нужно.
